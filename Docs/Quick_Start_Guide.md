# Quick Start Guide - Gabriel's Monster Arena

## Immediate Next Steps

### 1. Download and Install Godot 4

1. **Download Godot 4.x** from [godotengine.org](https://godotengine.org/download)
   - Choose the "Standard" version (not .NET)
   - Download for Windows (or your development platform)

2. **Install Godot**
   - Extract the downloaded file to a folder like `C:\Godot\`
   - No installation required - just run the executable

### 2. Get the Starter Template

1. **Download the Template**
   - Go to the Godot Asset Library: [godotengine.org/asset-library/asset/3243](https://godotengine.org/asset-library/asset/3243)
   - Click "Download" to get the template project

2. **Extract the Template**
   - Extract the downloaded file to a temporary folder
   - Copy the contents to a new folder: `Gabriel's Game/Template/`

### 3. Set Up Development Environment

1. **Open Godot**
   - Run the Godot executable
   - Click "Import" and navigate to your template folder
   - Select the `project.godot` file and import

2. **Test the Template**
   - Press F5 or click the "Play" button
   - The template should run with a basic tower defense game

### 4. VS Code Setup (Optional but Recommended)

1. **Install Godot Extension**
   - Open VS Code
   - Install the "godot-tools" extension
   - This provides syntax highlighting and debugging support

2. **Configure External Editor**
   - In Godot, go to Editor → Editor Settings
   - Set External Editor to VS Code
   - This allows editing scripts in VS Code

## Troubleshooting Common Issues

### Godot Won't Start
- Make sure you downloaded the correct version for your system
- Check that your graphics drivers are up to date
- Try running as administrator if needed

### Template Won't Import
- Ensure you're using Godot 4.x (not 3.x)
- Check that the template files aren't corrupted
- Try downloading the template again

### Game Won't Run
- Check the Output panel in Godot for error messages
- Make sure all required files are in the project folder
- Verify that the main scene is set correctly
